# Jimin Hong — Design & Digital Portfolio

## 로컬 실행

저장소를 내려받고 루트 폴더에서 실행합니다.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 http://127.0.0.1:8000/ 을 엽니다. 조절점을 드래그하거나 Tab으로 선택한 뒤 방향키로 움직여 보세요. Plan-Do-See 체험판은 가상 데이터를 사용합니다.
